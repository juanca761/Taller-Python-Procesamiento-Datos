## Presentación

Este repositorio contiene el desarrollo del primer taller del curso, enfocado en repasar los
fundamentos de Python (estructuras de datos, control de flujo, funciones y clases) como base
para las herramientas de procesamiento a gran escala que se trabajarán más adelante en el curso.

Cada cuaderno incluye el desarrollo de los ejercicios propuestos, documentación personal breve
de cada solución y una conclusión final que resume los conceptos trabajados.

## Contenido de los cuadernos

| Cuaderno | Tema | Descripción |
|---|---|---|
| `01-Python-Cadenas.ipynb` | Cadenas | Indexación, slicing, stride, secuencias de escape y métodos como `upper()`, `replace()` y `find()`. |
| `02-Python-Tuplas.ipynb` | Tuplas | Indexación, slicing, anidamiento, concatenación e inmutabilidad frente a las listas. |
| `03-Python-Listas.ipynb` | Listas | Indexación, slicing, mutabilidad, copia por referencia vs. por valor, `append()` y `extend()`. |
| `04-Python-Conjuntos.ipynb` | Conjuntos | Eliminación de duplicados, operaciones lógicas (unión, intersección, diferencia) y subconjuntos. |
| `05-Python-Diccionarios.ipynb` | Diccionarios | Pares llave-valor, acceso por llave, y métodos `keys()` y `values()`. |
| `06-Python-Condiciones.ipynb` | Condiciones | Operadores de comparación, sentencias `if`/`elif`/`else` y operadores lógicos. |
| `07-Python-Bucles.ipynb` | Bucles | Uso de `range()`, bucles `for` y `while`, e iteración sobre listas. |
| `08-Python-Funciones.ipynb` | Funciones | Definición de funciones, parámetros, `return`, variables locales vs. globales. |
| `09_Python_Clases.ipynb` | Clases | Definición de clases, constructor `__init__`, atributos y métodos; incluye la actividad de la clase Elipse. |
| `Lab01_Procesamiento_10Bono.ipynb` | Bono | Ejercicios integradores que combinan cadenas, listas, condiciones, bucles y funciones. |

## Conclusiones generales

El desarrollo de este taller permitió repasar de forma práctica las estructuras de datos y de
control fundamentales de Python, evidenciando cómo se combinan entre sí para resolver problemas
más completos (como en el cuaderno de Bono). Estas bases son necesarias para abordar, más
adelante en el curso, el trabajo con datos a gran escala, bases de datos NoSQL y herramientas
como Apache Spark.
